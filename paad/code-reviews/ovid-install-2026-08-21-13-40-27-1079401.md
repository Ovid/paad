The branch does what it says — npx install path, bare skill names, `help` -> `paad-help` — but the bare-name rewrite silently killed the export pipeline's only mechanism for stripping Claude Code invocation syntax. `scripts/convert_skills.py`'s `neutralize()` and `neutralize_description()` are both keyed on the `/paad:` prefix that no longer exists in any source, so the committed `kiro_and_antigravity/` tree now ships 31 un-runnable slash commands (0 on `main`) plus six frontmatter descriptions that leak a command, and `Makefile:262`'s guard against exactly that is keyed on the same dead string, so `make check-export-frontmatter` passes green. No Critical findings. Ten Important and seven Suggestion findings are in-scope; the README specifically carries the largest share, mostly in the new migration block, which can silently nest a user's reports one directory below where the skills look.
